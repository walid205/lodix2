# Lodix – تحويل إلى APK عبر GitHub Actions

1. استبدل محتوى `src/App.jsx` بالكود الكامل الخاص بك.
2. أنشئ مستودعاً جديداً على GitHub وارفع كل ملفات المشروع (بما فيها مجلد `.github`).
3. افتح تبويب **Actions** ← **Build Android APK** ← انتظر 5–8 دقائق.
4. حمّل ملف `Lodix-APK` من قسم **Artifacts** (ملف zip بداخله `app-debug.apk`).

## تشغيل محلي
```
npm install
npm run dev
```
